
# Data Center Operations Platform

An end-to-end data engineering and AI-powered
monitoring platform for simulated data center
infrastructure.

## Core Features

- Continuous synthetic telemetry generation
- Automated daily data ingestion
- Bronze, Silver and Gold data architecture
- PySpark-based ETL processing
- DuckDB analytical query engine
- Power BI operational dashboards
- Anomaly detection and predictive analytics
- AI-powered natural language to SQL copilot

## Technology Stack

Python, PySpark, DuckDB, Parquet, Pandas,
Power BI, Streamlit, Ollama and Gemini API.

## Telemetry Configuration

- 5 simulated data centers
- 500 simulated servers
- 15-minute collection intervals
- 24,000 records per day

## Architecture

Local-first and cloud-independent.
